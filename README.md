# Auto Shooter 試作版

Firefoxのサイドバーで動く、タッチ操作のシューティング試作です。拡張ボタンで起動し、戦闘画面を左右にドラッグして移動します。射撃は自動です。敵を倒すと撃破数が増え、自機のHPがなくなると2秒後に復帰します。敵は繰り返し出現します。数値や復帰方法は実機確認のための仮設定です。

## 読み込みと起動

1. Firefoxで `about:debugging#/runtime/this-firefox` を開く。
2. 「一時的なアドオンを読み込む」を選び、このフォルダー内の `extension/manifest.json` を指定する。
3. ツールバーまたは拡張機能メニューの「Auto Shooter」を押す。サイドバーが開き、ゲームが始まる。
4. 戦闘画面の「−」で最小化し、「ゲームに戻る」で復帰する。拡張ボタンからも復帰できる。

一時的なアドオンはFirefox終了時に削除されるため、次回は再度読み込みます。ゲーム状態は保存せず、Firefox終了・拡張の再読み込みでリセットされます。終了中の時間は進みません。サイドバーを閉じてもFirefoxと拡張が起動中ならゲームは続きます。

## 実機で確認すること

- Firefox 157.0.1、Surfaceの表示倍率200%、縦横それぞれで、起動、ドラッグ、タブ切り替え、最小化と復帰ができるか。
- サイドバーの幅や位置が作業の邪魔にならないか。最小化時は中身を復帰ボタンだけにしますが、サイドバーの領域自体はFirefoxが管理するため残ります。小さなボタンだけをページ上に残す要件は、この方式では達成できていません。
- Cage環境や画面消灯・復帰後に表示と進行がどうなるか。Firefoxのタイマーが遅れた場合は次の実行時に経過分を計算しますが、実機で継続性を確認する必要があります。
- サイドバーはブラウザーウィンドウごとに管理され、他のサイドバーに切り替えたり閉じたりすると表示されません。拡張ボタンで再表示できます。

ページの内容へのアクセス権限や外部通信は使いません。Firefox標準のサイドバーについては [Mozillaの説明](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/user_interface/Sidebars) を参照してください。
