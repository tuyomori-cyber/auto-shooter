# Auto Shooter 試作版

Firefoxのサイドバーで動く、タッチ操作のシューティング試作です。拡張ボタンで起動し、戦闘画面を左右にドラッグして移動します。射撃は自動です。敵を倒すと撃破数が増え、自機のHPがなくなると2秒後に復帰します。敵は繰り返し出現します。数値や復帰方法は実機確認のための仮設定です。

## 読み込みと起動

1. Firefoxで `about:debugging#/runtime/this-firefox` を開く。
2. 「一時的なアドオンを読み込む」を選び、このフォルダー内の `extension/manifest.json` を指定する。既に読み込んでいる場合は拡張機能を再読み込みする。
3. ツールバーまたは拡張機能メニューの「Auto Shooter」を押すと、サイドバーが開く。Firefoxのサイドバーメニューからも開ける。
4. ゲーム内の「−」でサイドバーを閉じられる。拡張ボタンから再び開ける。

一時的なアドオンはFirefox終了時に削除されるため、次回は再度読み込みます。ゲームはサイドバーを閉じても進行し、Firefox終了・拡張の再読み込みでリセットされます。終了中の時間は進みません。

## 実機で確認すること

- Firefox、Surfaceの表示倍率200%、縦横それぞれで、起動、ドラッグ、サイドバーの開閉と幅の変更ができるか。
- サイドバーの幅や表示位置が作業の邪魔にならないか。
- Cage環境や画面消灯・復帰後に表示と進行がどうなるか。Firefoxのタイマーが遅れた場合は次の実行時に経過分を計算しますが、実機で継続性を確認する必要があります。
